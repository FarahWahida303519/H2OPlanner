1.0	INTRODUCTION

H20 Planner is application that can help a users to calculate the daily water intake. The calculation of this application is based on their weight, temperature and activity level. The output will display the recommended water that their need to intake in liters per day.
2.0	THE PROCESS OF APPLICATION

a.	Input
	The user need to input their weight in kg in the text field, select the temperature and activity level from drop down button.
b.	Process
	The app will do the calculation inside calculate() :
-	Base formula : weight*0.035
-	If activity is low, then it will add 0.5 liters.
-	If activity is high,then it will add 1.0 liter
-	If temperature is hot, then it will add 0.5 liters.
	By using setState(), everytime refreshes, the display automatically update new value.

c.	Output
	The output will display the recommended daily water  that need to intake in the format liter.
	If user enter empty or 0 input, it will display the validation message. 
	A reset button can help to restore the display to normal.



3.0	WIDGET LIST USED

a.	AppBar : The top bar showing the title “Drink Calculator”.
b.	Text : Display the label.
c.	TextField : Accept input from user (kg).
d.	TextEditingController : Manages input inside the TextField
e.	DropdownButton : The user choose Temperature (Hot/Cool) and Activity (Low/High).
f.	ElevatedButton : Used for the Calculate and Reset buttons.
g.	Row : Arranges widgets horizontally.
h.	Column :  Arranges widgets vertically.
i.	Container : Provides box styling, background color, borders and shadows for layout and results.
j.	SizedBox : Adds spacing between widgets and sets widget with width or height.
k.	BoxDecoration  : To make a rounded corners and shadows for a card-like look.
l.	Image.asset  : Displays the app logo on the splash screen.
m.	CircularProgressIndicator : To shows the loading animation on the splash screen.
4.0	BASIC VALIDATION APPROACH 

	The validation messages will help to alert the user.
	If user not enter any input in the text field, it will display “ Please enter your weight!”.
	If user enter input with ‘0’, it will display the validation message “ Please enter a valid weight!”.
	Validation feedback is displayed directly on the screen inside the result box, so the user can immediately see what went wrong.
	This ensures the app does not crash when the input is missing or invalid, and it helps guide the user to enter correct data.
